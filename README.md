## E-Commerce Customer Churn Analysis

E-Commerce Customer Churn Analysis and Dashboard developed using Microsoft Excel to identify customer churn patterns and key factors influencing customer retention.

## Project Overview

This project analyzes e-commerce customer data to understand churn behavior and identify patterns among retained and churned customers.

## Tools Used
Microsoft Excel

## Dashboard

The Excel dashboard provides interactive visualizations to understand customer churn trends and compare churned and retained customers.

## Key Findings

Total Customers: 5630

Churned Customers: 948

Retained Customers: 4682

Overall Churn Rate: 17%
